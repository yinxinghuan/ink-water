# Ink & Water 视觉方向

## 视觉承诺

不是“仿水墨”的二维笔刷，而是把原作的实体笔尖、带阴影的水面和会自行生长的彩色墨迹完整带到触屏上。用户第一次滑动就应看到墨迹在指后延迟扩散。

## 色彩与材质

- 水面底色：`#332e2e`
- 初始笔尖：`#7beeff`
- 墨色：沿三个不同频率的正弦通道连续变化，沿用原作计算
- UI 象牙白：`#f2eee5`
- 深色文字：`#171515`
- UI 只使用 1px 边线、轻度背景模糊和硬朗直角，不添加霓虹胶囊或拟物按钮。

## 构图

- 相机沿用原作 `(0, 7, 8)` 看向原点，平面尺寸 `30×30`。
- 标题位于安全区顶部左侧；进度位于顶部右侧。
- 隐藏操作提示只描述“双指开合调水”，位于底部安全区。
- 结算板位于底部，不覆盖画面中央的笔尖和主要墨迹。

## 动效

- 首屏抽象墨层缓慢呼吸，但不创建 Canvas/WebGL。
- 幽灵手指沿一条短弧移动，并通过与玩家相同的注入路径产生真实墨迹。
- 结算板用 `280ms` 上移淡入；弱动效偏好下取消循环和路径演示。

## 反模式

- 不使用设备外框、视频播放三角或手机游戏描述。
- 不用大量说明文字教单指操作。
- 不用普通 Canvas 粒子替代原作 FBO shader。
- 不把噪声数据纹理误当作可替换的内容图片。
